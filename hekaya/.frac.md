## 1. 本目录是什么

静态资源根：AI 生成媒体、可商用占位与合作方成片，按用途分五个子目录。standalone 部署时需随包拷贝（deploy-cloud.sh 已处理），Pages 部署自动带上（注意 basePath）。

## 2. 直属文件

无直属文件（媒体均在子目录）。

## 3. 子目录导航

- `covers/`：见 `covers/.frac.md`；九剧海报封面（d1-d6 Seedream / d7-d9 成片截帧）。
- `frames/`：见 `frames/.frac.md`；分集初始帧（d1-d6 生成 9 张轮换 / d7-d9 逐集截帧）。
- `episodes/`：见 `episodes/.frac.md`；合作方三部成片的 16 个分集视频（逐集播放）。
- `samples/`：见 `samples/.frac.md`；套装 A 占位样片 + TTS 配音。
- `samples-live/`：见 `samples-live/.frac.md`；套装 B 真实生成产物（含 d1 正片）。

## 4. 本层约束 / 约定 / 禁忌

- 媒体文件名即前端协议，重命名必须同步 `src/lib/samples.ts` / `src/components/Poster.tsx`。
- 体积意识：全部为压缩产物 git 直存（当前约 140MB 级）；新增成片必须走 720p H.264 低码率转码，禁 HEVC。
